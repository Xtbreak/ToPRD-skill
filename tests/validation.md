# 验证记录

2026-11-09 创建版本。

## 基线

独立代理未加载 ToPRD 时执行场景 A，先输出“建议的首版方案，待你确认”的基础稿，自行提出暂缓扫描件 OCR 等范围，再在文末询问目标用户。与先澄清、范围由用户决定、正式文档清洁交付的要求不一致。

## 加载 Skill 后

另一独立代理读取 Skill 和相关引用后模拟执行 A—E 五个场景。

| 场景 | 观察结果 |
|---|---|
| A 模糊想法 | 先询问目标用户和核心任务，沿用 PDF、编辑导出和未评测事实，没有输出占位终稿。 |
| B 文档与代码冲突 | 询问目标版本和预期发送行为，未把没有评测文件当成从未评测。 |
| C 确认未评测 | 在正文加粗未评测、无线上效果数据，未编造结果或重复询问。 |
| D 可选产物 | 只交付 PRD 与已授权的独立面试问答，未额外生成详解。 |
| E 范围变更 | 对 PDF 与 Word 范围冲突先询问，再给出确认后的润色示例。 |

根据评审补充两条规则：真实缺失状态可替代空表，未选择的额外文档不阻塞已授权产物。
